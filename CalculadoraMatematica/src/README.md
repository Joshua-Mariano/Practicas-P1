# Calculadora Matemática en Java

## Descripción
Este proyecto consiste en una calculadora matemática desarrollada en Java que permite realizar operaciones básicas utilizando dos números ingresados por el usuario.

El programa utiliza un menú interactivo para seleccionar la operación que se desea realizar y continúa ejecutándose hasta que el usuario elige la opción de salir.

## Funcionalidades
- Ingresar dos números.
- Sumar dos números.
- Restar dos números.
- Multiplicar dos números.
- Dividir dos números.
- Validar la división entre cero.
- Salir del programa mediante un menú interactivo.

## Clases del proyecto

**CalculadoraMatematica.java**

Contiene los atributos para almacenar los dos números y los métodos encargados de realizar las operaciones matemáticas.

**CalculadoraMain.java**

Contiene el método principal `main`, muestra el menú de opciones, recibe los datos del usuario mediante `Scanner` y ejecuta las operaciones utilizando una estructura `switch` y un ciclo `do-while`.

## Tecnologías utilizadas
- Java
- NetBeans IDE
- Clase `Scanner` para la entrada de datos.
- Estructuras `switch` y `do-while`.
- Métodos, atributos y constructores.

## Cómo ejecutar el programa
1. Abrir el proyecto en NetBeans.
2. Verificar que ambas clases estén dentro del mismo paquete.
3. Ejecutar la clase `CalculadoraMain.java`.
4. Seleccionar una opción del menú e ingresar los números cuando corresponda.

## Ejemplo de uso

```text
=== CALCULADORA MATEMATICA ===
1. Ingresar numeros
2. Sumar
3. Restar
4. Multiplicar
5. Dividir
0. Salir
Seleccione una opcion:
```
