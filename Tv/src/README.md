# Clase TV

Este proyecto en Java demuestra el uso de **Programación Orientada a Objetos (POO)** mediante la creación y manejo de objetos de tipo `Tv`.

El programa crea tres televisores con diferentes características y utiliza métodos para encenderlos, apagarlos y controlar su volumen.

## Funcionamiento

La clase `Tv` contiene los siguientes atributos:

* `marca`
* `pulgadas`
* `encendido`
* `volumen`

También contiene métodos para controlar el televisor:

* `encender()`
* `apagar()`
* `subirVolumen()`
* `bajarVolumen()`

En la clase `Prueba` se crean tres objetos `Tv`:

* Samsung de 55 pulgadas.
* LG de 48 pulgadas.
* Sony de 36 pulgadas.

Cada televisor es encendido y se prueba el funcionamiento de los controles de volumen antes de apagarlo.

## Conceptos utilizados

* Programación Orientada a Objetos (POO).
* Clases y objetos.
* Atributos.
* Métodos.
* Constructores.
* Condicionales `if - else`.
* Creación de múltiples objetos.
