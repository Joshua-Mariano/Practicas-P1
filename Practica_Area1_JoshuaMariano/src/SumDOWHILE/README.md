# Sumatoria del 1 al 50

Este programa en Java calcula la **sumatoria de los números del 1 al 50** utilizando un ciclo `do-while`.

## Funcionamiento

El programa:

1. Inicializa una variable `suma` en `0`.
2. Comienza el contador `i` desde `1`.
3. Utiliza un ciclo `do-while` para sumar cada número.
4. Incrementa el contador hasta llegar al número 50.
5. Muestra el resultado de la sumatoria en la consola.

## Ejemplo

```text
La sumatoria de los números del 1 al 50 es: 1275
```

## Tecnologías utilizadas

* Java
* Ciclo `do-while`.
* Variables de tipo `int`.
* Operador `+=`.
* `System.out.println()` para mostrar el resultado.
