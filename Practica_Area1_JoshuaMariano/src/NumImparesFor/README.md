# Números Impares del 1 al 100

Este programa en Java muestra en la consola todos los números impares desde el **1 hasta el 100**.

## Funcionamiento

El programa utiliza un ciclo `for` para recorrer los números comenzando desde 1.

En cada repetición, el valor aumenta de 2 en 2, por lo que únicamente se muestran números impares.

## Ejemplo

```text
Números impares del 1 al 100:
1 3 5 7 9 11 13 15 17 ... 97 99
```

## Tecnologías utilizadas

* Java
* Ciclo `for`.
* `System.out.print()` para mostrar los números en consola.

## Clase principal

```text
NumImparesFor
```
