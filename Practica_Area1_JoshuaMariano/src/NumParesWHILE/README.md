# Números Pares del 2 al 100

Este programa en Java muestra en la consola todos los números pares desde el **2 hasta el 100**.

## Funcionamiento

El programa utiliza un ciclo `while` para recorrer los números.

Comienza desde el número 2 y aumenta de 2 en 2 hasta llegar al 100, mostrando únicamente los números pares.

## Ejemplo

```text
Números pares del 2 al 100:
2 4 6 8 10 12 14 16 18 ... 96 98 100
```

## Tecnologías utilizadas

* Java
* Ciclo `while`.
* `System.out.print()` para mostrar los números en consola.
