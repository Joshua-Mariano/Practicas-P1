# Determinar Número Par o Impar

Este programa en Java permite ingresar un número entero y determinar si es **par** o **impar**.

## Funcionamiento

El programa:

1. Solicita al usuario que ingrese un número.
2. Utiliza el operador `%` para obtener el residuo de la división entre 2.
3. Si el residuo es `0`, determina que el número es par.
4. Si el residuo es diferente de `0`, determina que el número es impar.

## Ejemplo

```text
Ingresa un número: 8
El número 8 es par.
```

Otro ejemplo:

```text
Ingresa un número: 7
El número 7 es impar.
```

## Tecnologías utilizadas

* Java
* `Scanner` para recibir datos desde el teclado.
* Estructura condicional `if - else`.
* Operador módulo `%`.

## Clase principal

```text
DetNumParoImpar
```
