# Tabla de Multiplicar

Este programa en Java permite al usuario ingresar un número y muestra su **tabla de multiplicar del 1 al 10**.

## Funcionamiento

El programa:

1. Solicita al usuario un número.
2. Utiliza un ciclo `for` para recorrer los números del 1 al 10.
3. Multiplica el número ingresado por cada valor del ciclo.
4. Muestra cada operación y su resultado en la consola.

## Ejemplo

```text
Ingresa el número para ver su tabla de multiplicar: 5

Tabla del 5:
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

## Tecnologías utilizadas

* Java
* `Scanner` para recibir datos desde el teclado.
* Ciclo `for`.
* Operadores matemáticos.
* `System.out.println()` para mostrar los resultados.
