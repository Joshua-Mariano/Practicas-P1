# Operaciones Matemáticas Básicas

Este programa en Java realiza las cuatro operaciones matemáticas básicas utilizando dos números: **suma, resta, multiplicación y división**.

## Funcionamiento

El programa utiliza los números `15` y `2` y realiza las siguientes operaciones:

* Suma
* Resta
* Multiplicación
* División

Luego muestra los resultados de cada operación en la consola.

## Ejemplo

```text
La suma de 15 y 2 es: 17
La resta de 15 y 2 es: 13
La multiplicacion de 15 y 2 es: 30
La division de 15 y 2 es: 7.0
```

## Tecnologías utilizadas

* Java
* Variables de tipo `int` y `double`.
* Operadores matemáticos `+`, `-`, `*` y `/`.
* `System.out.println()` para mostrar los resultados.
