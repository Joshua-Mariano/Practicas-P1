# Información Personal

Este programa en Java muestra información personal básica del usuario mediante mensajes en la consola.

## Funcionamiento

El programa:

1. Guarda el nombre del usuario en una variable `String`.
2. Guarda el correo electrónico en otra variable `String`.
3. Muestra ambos datos en un mensaje de bienvenida.

## Ejemplo

```text
Bienvenido Joshua Mariano, usuario del correo: Joshua.Mariano08@gmail.com
```

## Tecnologías utilizadas

* Java
* Variables de tipo `String`.
* `System.out.println()` para mostrar información en consola.

## Clase principal

```text
InfoPersonal
```
