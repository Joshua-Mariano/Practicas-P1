# Comparar Dos Números

Este programa en Java permite ingresar dos números y determinar cuál de los dos es **mayor** y cuál es **menor**.

Si los dos números son iguales, el programa también lo indica.

## Funcionamiento

El programa:

1. Solicita al usuario el primer número.
2. Solicita el segundo número.
3. Compara ambos números.
4. Muestra cuál es el mayor y cuál es el menor.
5. Si son iguales, muestra un mensaje indicándolo.

## Ejemplo

```text
Ingresa el primer número: 15
Ingresa el segundo número: 8

El número mayor es: 15
El número menor es: 8
```

## Tecnologías utilizadas

* Java
* `Scanner` para recibir datos desde el teclado.
* Estructuras condicionales `if`, `else if` y `else`.

## Clase principal

```text
CompararNumerosMayoryMenor
```
